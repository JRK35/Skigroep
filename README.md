# Skigroep

Groepsapp voor de skireis naar Tignes: meldingen, posities, routes per dag, logboek en kaart.

- App: https://jrk35.github.io/Skigroep/
- Meldingen lopen via [ntfy](https://ntfy.sh). Het groepskanaal staat **niet** in deze code; dat zit alleen in de uitnodigingslink.
- Kaartgegevens en plaatsnamen © OpenStreetMap-bijdragers, pistes © OpenSnowMap.
